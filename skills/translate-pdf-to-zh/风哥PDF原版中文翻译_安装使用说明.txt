风哥PDF原版中文翻译 Skill
Codex 安装与使用说明

==================================================
一、这个 Skill 的常用用途
==================================================

本 Skill 用于将电子文字版的英文或西班牙语 PDF 转换为简体中文 PDF，
并尽量保持原文的页面尺寸、颜色、底纹、图片、表格和文字位置。

常用用途：

1. 英文 PDF 转中文 PDF。
2. 西班牙语 PDF 转中文 PDF。
3. 翻译正文、章节标题、页眉和目录。
4. 表格只翻译表格标题和最上方列标题，表格正文保持原文。
5. 图表内部文字保持原文，只翻译图外的图题和图注。
6. 公式、页码、Logo、网址、独立数字和缩写保持原文。
7. 支持100至200页长文件，默认每20页自动处理一批，最后自动合并。
8. 输出为图像型 PDF，主要追求视觉版式一致，不支持搜索和复制中文。

适用文件：

- 有可选择文字的电子版 PDF。
- 英文或西班牙语 PDF。
- 包含正文、目录、表格、图片、图表和公式的报告。

不适用文件：

- 扫描件或纯图片 PDF。此类文件需要先进行 OCR。
- 需要可搜索、可复制中文文字层的任务。
- 要求百分之百还原所有复杂排版细节的出版级文件。


==================================================
二、安装到 Codex
==================================================

1. 解压压缩包。

2. 将完整的 translate-pdf-to-zh 文件夹复制到：

   C:\Users\你的Windows用户名\.codex\skills\translate-pdf-to-zh

   不能只复制 SKILL.md，必须保留 agents、lib、references 和 scripts 等目录。

3. 安装 Python 依赖。

   打开 PowerShell，执行：

   py -3.12 -m pip install -r "$HOME\.codex\skills\translate-pdf-to-zh\requirements.txt"

   依赖的作用：

   - PyMuPDF：读取、分析、拆分和合并 PDF。
   - Pillow：绘制中文和处理页面图像。
   - requests：调用 DeepSeek 翻译接口。

4. 完全退出并重新启动 Codex。

5. 测试 Skill：

   使用风哥PDF原版中文翻译分析这个PDF，只生成分析报告，暂不翻译。


==================================================
三、申请 DeepSeek API Key
==================================================

API Key 不是需要安装的软件。它相当于调用 DeepSeek 接口的个人密码。

1. 打开 DeepSeek 开放平台：

   https://platform.deepseek.com/

2. 注册或登录自己的 DeepSeek 账号。

3. 进入 API Keys 页面，创建一个新的 API Key。

4. 创建后立即保存。平台通常不会再次完整显示该密钥。

5. 检查账户余额。DeepSeek API 按输入和输出文字量计费。

官方接口文档：

https://api-docs.deepseek.com/

官方价格页面：

https://api-docs.deepseek.com/quick_start/pricing

价格和模型名称可能调整，使用前以官方页面为准。


==================================================
四、在 Windows 中配置 API Key
==================================================

方法一：使用系统界面

1. 按 Windows 键，搜索：

   编辑系统环境变量

2. 打开后点击：

   环境变量

3. 在用户变量区域点击：

   新建

4. 填写：

   变量名：DEEPSEEK_API_KEY
   变量值：你自己申请的 DeepSeek API Key

5. 连续点击确定。

6. 完全关闭并重新打开 Codex。

方法二：使用 PowerShell

执行：

setx DEEPSEEK_API_KEY "你自己申请的DeepSeek API密钥"

执行后必须重新启动 Codex，旧窗口不会自动读取新变量。

安全提醒：

- 不要把 API Key 发给别人。
- 不要把 API Key 写进 SKILL.md 或任何 Python 文件。
- 不要把包含 API Key 的截图上传到网络。
- 每位使用者都应申请和使用自己的 API Key。
- 如果怀疑密钥泄露，应立即到 DeepSeek 平台删除旧密钥并创建新密钥。


==================================================
五、基本使用方法
==================================================

分析 PDF，不进行翻译：

使用风哥PDF原版中文翻译分析这个PDF，只生成分析报告，暂不翻译。

正式翻译：

使用风哥PDF原版中文翻译，将这个英文PDF翻译成中文PDF，保持原版式。

翻译西班牙语 PDF：

使用风哥PDF原版中文翻译，将这个西班牙语PDF翻译成中文PDF。

默认规则：

- 默认使用标准质量：240 DPI、JPEG质量92。
- 默认每20页自动处理一批。
- 不需要用户逐批确认。
- 全部批次完成后自动合并为一个 PDF。
- 文字放不下时依次采用精简译文、增加行数、最多缩小15%，最后缩小到80%。
- 不覆盖原文件。


==================================================
六、常见问题
==================================================

1. 提示 Missing DEEPSEEK_API_KEY

原因：Codex 没有读取到 Windows 环境变量。

处理：

- 检查变量名是否为 DEEPSEEK_API_KEY。
- 完全退出并重新启动 Codex。
- 必要时注销 Windows 或重新启动电脑。

2. 提示认证失败或 HTTP 401

原因：API Key 错误、被删除或已经失效。

处理：

- 到 DeepSeek 平台检查密钥。
- 重新创建密钥并更新环境变量。

3. 提示余额不足或 HTTP 402

原因：DeepSeek API 账户余额不足。

处理：

- 登录 DeepSeek 开放平台检查余额。
- 是否充值由使用者自行决定。

4. 提示缺少 fitz、PIL 或 requests

原因：Python 依赖没有安装。

处理：

py -3.12 -m pip install -r "$HOME\.codex\skills\translate-pdf-to-zh\requirements.txt"

5. 扫描 PDF 无法处理

原因：PDF 没有可选择的文字层。

处理：

- 先使用 OCR 软件识别文字。
- 再将 OCR 后的 PDF 交给本 Skill。

6. 长文件处理中断

重新执行相同任务。程序会检查已经完成的批次，并尽量从未完成的位置继续。


==================================================
七、隐私与费用说明
==================================================

正式翻译时，PDF中需要翻译的文字会发送给 DeepSeek API。
图片和完整 PDF 文件不会作为文件直接上传，但提取出的文字内容会发送给模型。

请勿使用本 Skill 处理不允许发送给第三方服务的机密文件。

DeepSeek API 会产生费用，具体金额取决于输入和输出文字量。
官方价格可能调整，请以 DeepSeek 官方价格页面为准。
